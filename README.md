# Xiaomi Sky Kernel Builder

GitHub Actions workflow to build kernel (`kernel_xiaomi_sky`) and hardware vendor modules (`kernel_xiaomi_sky-modules`) for Xiaomi Sky (Redmi Note 12R / Redmi 12 5G / POCO M6 Pro 5G).

## Sources Used
- Kernel Tree: [AltafYafai/kernel_xiaomi_sky](https://github.com/AltafYafai/kernel_xiaomi_sky)
- Modules Tree: [AltafYafai/kernel_xiaomi_sky-modules](https://github.com/AltafYafai/kernel_xiaomi_sky-modules)
- Target Branch: `lineage-24.0`

## How to Run
1. Go to the **Actions** tab in this repository.
2. Select **Build Xiaomi Sky Kernel (lineage-24.0)**.
3. Click **Run workflow** and choose your desired options.
